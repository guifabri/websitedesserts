# Dulce Capricho

Dulce Capricho es un sitio web moderno y elegante para una pastelería artesanal especializada en postres irresistibles. La página presenta una identidad visual cálida y dulce inspirada en una paleta pastel con tonos suaves, ideal para una marca de repostería premium.

## Características
- Navbar con logo y nombre de la empresa
- Menú responsive con hamburguesa para móvil
- Hero principal con imagen destacada y llamadas a la acción
- Sección central de marca con CTA
- Galería de postres en tarjetas con información visual
- Footer con navegación, redes sociales y contacto
- Diseño adaptable para desktop y móviles

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Uso
Abre el archivo `index.html` en el navegador para visualizar el sitio.
